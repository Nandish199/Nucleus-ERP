# 🚀 Nucleus ERP Frontend

A modern, responsive frontend application for the **Nucleus ERP (Enterprise Resource Planning)** system, built with **React, TypeScript, Vite, and Tailwind CSS**. The application provides an intuitive interface for managing business operations such as employees, customers, inventory, sales, and financial records.

---

## 📖 Overview

Nucleus ERP is designed to simplify business management by providing a centralized platform for handling day-to-day operations. This repository contains the frontend client, offering a clean, responsive, and user-friendly experience while communicating with backend APIs.

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/your-username/nucleus-erp.git
```

### Navigate to the Project

```bash
cd nucleus-erp
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```

---

## 📦 Build for Production

```bash
npm run build
```

---

## 🔍 Preview Production Build

```bash
npm run preview
```

---

## 🌐 Environment Variables

Create a `.env` file in the project root.

```env
VITE_API_URL=http://localhost:5000/api
```

> **Note:** All client-side environment variables must start with the `VITE_` prefix.
